  1. Andá a console.firebase.google.com
  2. Creá un proyecto nuevo (ej: "fitpro-dashboard")
  3. Agregá una app Web (ícono </>)
  4. Copiá el objeto firebaseConfig que te da
  5. Creá una Realtime Database en modo prueba
  6. Pegá la config acá abajo
